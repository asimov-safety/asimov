Integration

Test your system.

Use your existing agent framework, IAM, databases, lifecycle controls, supervisor, and audit systems. An adapter translates those native mechanisms into Asimov's semantic test operations.

1. Install

git clone https://github.com/asimov-safety/asimov.git
cd asimov
python -m pip install -e .

2. Verify the harness

python -m asimov_conformance reference-probes
python -m asimov_conformance reference-mutations
python -m asimov_conformance doctor --level A3

3. Map your architecture

SemanticTypical source
attempt()Agent framework / API / orchestrator
observe()Database, filesystem, external API, queue, executor
revoke()IAM, token broker, lease, policy controller
stop()Independent operator/supervisor path
restart()Container runtime / process manager / service manager
EvidenceAudit store, OpenTelemetry, AAS-1, resource-side records

4. Build the thin adapter

Claim only capabilities your deployment actually implements. The adapter translates; the deployment provides the control.

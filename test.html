Integration

Test your system.

Map your existing controls, connect them through a thin adapter, run readiness diagnostics, and execute the conformance probes.

01 · Install

Get Asimov

Install the reference tooling in a Python 3.10+ environment.

02 · Map

Identify native controls

Find your action driver, authority controller, resource oracle, lifecycle controller, supervisor, and evidence source.

03 · Doctor

Check readiness

Missing mandatory control surfaces appear as blockers with concrete remediation.

04 · Probe

Run the suite

Exercise the deployment and collect evidence-bound results.

Install

Validate the harness first.

git clone https://github.com/asimov-safety/asimov.git
cd asimov
python -m pip install -e .

python -m asimov_conformance reference-probes
python -m asimov_conformance reference-mutations
python -m asimov_conformance doctor --level A5
Adapter model

Connect to the controls you already run.

The adapter translates your infrastructure into Asimov semantics. Your actual system supplies the control.

SemanticTypical source
attempt()Agent framework / API / orchestrator
observe()Database, filesystem, external API, queue, executor
issue_grant() / revoke()IAM, token broker, policy engine, leases
stop()Out-of-band operator or supervisor path
restart()Kubernetes, systemd, launchd, Windows service control
SupervisionIndependent supervisor / control service
EvidenceAudit store, OpenTelemetry, AAS-1, resource-side records

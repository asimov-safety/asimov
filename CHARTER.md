# Asimov Charter

## Mission

Make human control of autonomous AI specific, testable, and inspectable across models, vendors, and software stacks.

## The standard

The Seven Constants provide the governing vocabulary of Asimov. Versioned requirements translate each Constant into engineering properties. The conformance suite probes those properties, preserves failures and uncertainty, and produces evidence-bound assessment results. The reference implementation demonstrates the standard in executable form.

AI providers, agent-framework builders, independent developers, deploying organizations, researchers, security teams, and assessors can implement Asimov with their own infrastructure.

## Project commitments

The specification, schemas, test definitions, and reference code are open and permissively licensed. Mandatory failures cannot be averaged away. Missing mandatory control surfaces block the affected profile. Requirements evolve through reviewable, versioned changes with recorded rationale.

Funding never buys exemptions from conformance criteria.

## Scope

Asimov evaluates technical control, supervision, intervention, delegation, and accountability properties for a defined deployment scope and threat model.

## Success criterion

A third party can read a requirement, implement it without depending on Asimov's runtime, run the associated test against a disposable deployment, reproduce the finding, and observe a deliberately broken implementation fail.
